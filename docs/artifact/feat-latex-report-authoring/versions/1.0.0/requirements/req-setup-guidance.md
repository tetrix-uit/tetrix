# req-setup-guidance: Give setup guidance

**Master:** [Requirements](README.md)
**Priority:** Must
**Context:** Not applicable

## Statement

The project must give setup guidance to each project contributor for the local XeLaTeX report
compilation environment.

## Acceptance criteria

- Given a project contributor uses the project development environment, when the contributor
  follows the setup guidance, then the contributor can compile a LaTeX report with XeLaTeX.
- Given a project contributor does not use the project development environment, when the
  contributor follows the setup guidance, then the contributor can compile a LaTeX report with
  XeLaTeX.

## Notes

The setup guidance must cover use of the project development environment and use without it.
