# req-local-compilation: Give a local report compilation environment

**Master:** [Requirements](README.md)
**Priority:** Must
**Context:** Not applicable

## Statement

The project must give each project contributor a repeatable local environment to write and compile
LaTeX reports with XeLaTeX.

## Acceptance criteria

- Given a project contributor has the local environment, when the contributor compiles a LaTeX
  report with XeLaTeX, then the compilation completes on the contributor's local computer.

## Notes

This requirement does not include report templates, report content, continuous integration, or
another LaTeX engine.
