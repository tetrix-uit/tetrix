# req-blocks: Draw the falling block shapes

**Master:** [Requirements](README.md)
**Priority:** Must
**Context:** context-tetrix-gameplay

## Statement

The game must draw each falling block shape inside the game well.

## Acceptance criteria

- Given a new falling block, when the block enters the well, then the player sees the full shape
  of the block.
