# req-square-ui: Draw a square border and square blocks

**Master:** [Requirements](README.md)
**Priority:** Must
**Context:** context-tetrix-gameplay

## Statement

The game must draw the border and the blocks with square cells.

## Acceptance criteria

- Given the game screen, when the player views the well, then each border cell has equal height
  and width.
- Given the game screen, when the player views a block, then each block cell has equal height
  and width.

## Notes

The reference sample screen shows a bordered well, a falling T piece, and stacked blocks at the
bottom. Phase 4 owner: SV3.
