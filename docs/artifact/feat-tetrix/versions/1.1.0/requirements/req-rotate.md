# req-rotate: Rotate the falling block

**Master:** [Requirements](README.md)
**Priority:** Must
**Context:** context-tetrix-gameplay

## Statement

The game must rotate the falling block on player demand.

## Acceptance criteria

- Given the falling block with free space to turn, when the player rotates the block, then the
  block turns 90 degrees clockwise.
- Given the falling block with no free space to turn, when the player rotates the block, then the
  block keeps its shape and place.
