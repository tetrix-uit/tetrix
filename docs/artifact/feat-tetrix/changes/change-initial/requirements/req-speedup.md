# req-speedup: Increase the falling speed after each cleared line

**Master:** [Requirements](README.md)
**Priority:** Must
**Context:** context-tetrix-gameplay

## Statement

The game must increase the falling speed after each cleared line.

## Acceptance criteria

- Given a cleared line, when the next block falls, then the timer period is shorter than the
  period before the cleared line.
