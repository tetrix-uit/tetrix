# req-screen: Draw the bordered game well

**Master:** [Requirements](README.md)
**Priority:** Must
**Context:** context-tetrix-gameplay

## Statement

The game must draw the game well with a border on all four sides.

## Acceptance criteria

- Given a new game, when the game starts, then the game well shows with a border on the top,
  bottom, left, and right sides.
- Given the falling block at the edge of the well, when the player moves the block toward the
  border, then the block stays inside the border.

## Notes

The size of the well follows the lecturer baseline. Phase 4 owner: SV1.
