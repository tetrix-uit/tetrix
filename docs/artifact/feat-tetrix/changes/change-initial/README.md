## Reason

Players need the Tetrix falling-block game in apps/tetrix. The lecturer baseline gives falling
blocks and movement, but it lacks line clearing, square display, rotation, and higher speed after
each cleared line. This change is the first build of the feature and defines all seven business
requirements.
