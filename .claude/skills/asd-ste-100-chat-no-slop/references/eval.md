# Chat No-Slop Eval

Use this after the draft. Answer each check with pass or fail. Fix each
failure before sending.

## Chat checks

1. Does the reply state the point first instead of clearing its throat?
2. Are banned words, empty adverbs, and empty phrases removed?
3. Are binary contrasts, faux-insight setups, colon reveals, puffery, and
   weasel attribution removed?
4. Does the reply end on a concrete point or a next action, with no kicker
   and no recap?
5. Does every generic sentence pass the portability test, or was it cut or
   made specific?
6. Is the formatting plain: no emoji headings, no decorative bold, no list
   that should be prose, no dash cluster?

## Delegate check

1. For a task that writes or edits a file under `docs/wiki/`,
   `docs/artifact/`, or the `services/factory/` assets, was `asd-ste-100`
   loaded for the file work?

## Final read

1. Would this reply sound natural if read to a sharp colleague?
2. Was accuracy kept above style, with each conflict noted?
