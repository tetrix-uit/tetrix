# Chat No-Slop Examples

## Binary contrast in a status reply

**Before:** It is not the model that is slow. It is the retrieval step
that costs the time.

**After:** The retrieval step costs the time. It adds 800 ms per query.

## Throat-clearing plus puffery

**Before:** Here is the thing. This launch marks a pivotal moment for
the team and underscores its significance going forward.

**After:** The team ships the first paid plan on Friday.

## Weasel attribution plus vague quantity

**Before:** Experts agree that the cache clears periodically, which
significantly improves performance.

**After:** The system clears the cache each 15 minutes. I have no source
for the performance claim, so I cut it. Do you have the numbers?

## Kicker and recap ending

**Before:** In conclusion, the fix is ready. Ultimately, the future is
not coming. It is already here.

**After:** The fix is ready. Review the diff and merge it.

## Delegate to asd-ste-100

**Before:** The agent writes the new wiki page in its own style.

**After:** The agent loads `asd-ste-100`, writes the page with the
dictionary and the review checklist, then runs the no-slop checks on
the result.
