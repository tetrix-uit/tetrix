# ASD-STE-100 Review Checklist

Use this checklist when you review a document. Give the rule number with each
comment.

## Pass 1: Structure

- [ ] Each paragraph has one topic. (6.3)
- [ ] Each descriptive paragraph has 6 sentences or fewer. (6.2)
- [ ] Each procedural paragraph has 6 sentences or fewer. (5.7)
- [ ] Each procedure is a numbered list. Each step is one action. (5.2, 5.3)
- [ ] Each warning and each caution is before the step that it applies to.
      (7.1)
- [ ] No note contains an instruction, a warning, or a caution. (9.2)
- [ ] The layout and the terminology are the same in the full document. (9.4)

## Pass 2: Sentences

- [ ] Each procedural sentence has 20 words or fewer. (5.6)
- [ ] Each descriptive sentence has 25 words or fewer. (6.1)
- [ ] Each sentence has one topic and one item of information. (4.5, 4.6)
- [ ] Each instruction starts with a verb in the imperative. (5.1)
- [ ] Each condition is before its instruction. (5.5, 7.3)
- [ ] The word order is subject, verb, object. (4.1)
- [ ] Connecting words show the relation between the sentences. (4.4)
- [ ] No sentence starts with a numeral. (8.8)

## Pass 3: Verbs

- [ ] No procedure uses the passive voice. (3.5)
- [ ] The descriptions use the active voice as much as possible. (3.4)
- [ ] Only the simple present, the simple past, and the simple future occur.
      (3.2, 3.3)
- [ ] No verb becomes a noun. Search for these endings: -tion, -ment, -ance,
      -ence, -al. (3.6)
- [ ] The -ing form occurs only in a technical name. (3.7)

## Pass 4: Words

- [ ] Each word is in the dictionary, or it is a technical name or a technical
      verb. (1.1)
- [ ] Each word has its approved part of speech. (1.2)
- [ ] Each word has its approved meaning. (1.3)
- [ ] One name identifies one thing in the full document. (1.5)
- [ ] One verb identifies one action in the full document. (1.6)
- [ ] No slang, no jargon, and no idiom occur. (1.9)
- [ ] The document defines each abbreviation at first use. (1.12)
- [ ] No contraction occurs. (1.13)

## Pass 5: Noun phrases and punctuation

- [ ] No noun cluster has more than three nouns. (2.1)
- [ ] Each noun has an article or a demonstrative. (2.3, 4.3)
- [ ] Each compound modifier has a hyphen. (2.4, 8.2)
- [ ] No slash means "and" or "or". (8.3)
- [ ] No parenthesis adds information to a sentence. (8.4)
- [ ] Each quantity is specific. (4.2)

## How to report the findings

For each finding, give these four items:

1. The location, such as the line number or the heading.
2. The rule number.
3. The text as it is now.
4. The proposed text.

If the meaning of a sentence is not clear, ask the author. Do not guess the
meaning and do not delete the sentence.
